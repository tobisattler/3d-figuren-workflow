# Beispiele aus den Läufen an „Sid“

Echte Abgaben der Fable-5.2-Subagenten (Effort xhigh), unverändert. Pfade darin beziehen sich auf unsere Box (`/home/visual/work/...`).

| Datei | Runde |
|---|---|
| `sid/notizen_v1_gesicht.md` | modelliertes Gesicht mit Ausdrücken |
| `sid/notizen_v3_kopfhoerer.md` | Kopfhörer als eigene Objekte |
| `sid/notizen_v4_aufraeumen.md` | Aufräumrunde, mit der Normal-Map als Ursache der Risse |
| `sid_rig/notizen_rig_v1.md` | Rig: Aufbau, Knochenliste, Gewichte, Prüfposen, Schwächen |
| `sid_rig/export_glb_sid.py` | Web-Export mit Steuer-Rig. Das Deform-Skelett `RIG_Sid_Game` wird aus dem Rigify-Rig `RIG_Sid` gebacken, mit 16-bit-Rotationen für Meshopt. Für eine andere Figur die Objektnamen und die Liste `ACTIONS` anpassen. |

Sie zeigen, wie ausführlich die Agenten prüfen und berichten, wenn der Auftrag es verlangt. Das ist eine gute Vorlage dafür, was man in der Abgabe erwarten kann.
